# Документация для интеграции с бэкендом

## 📋 Обзор проекта

Верстка интерактивного слайдера "Итоги года 2025" для Яндекс Маркет. Проект представляет собой одностраничное приложение с автоматической сменой карточек.

**Текущая версия**: Статическая верстка с захардкоженными данными


## 🔧 Технические детали

### Зависимости
- **Нет внешних зависимостей** - чистый vanilla JavaScript
- Все стили в одном файле `styles.css`
- Все логика в одном файле `script.js`

### Браузерная поддержка
- Современные браузеры (Chrome, Firefox, Safari, Edge)
- Поддержка ES6+ JavaScript
- Поддержка CSS Grid и Flexbox
- Поддержка Touch Events для мобильных устройств

### Адаптивность
- **Desktop**: от 1200px
  - 3 карточки одновременно (левая, центр, правая)
  - Стрелки навигации видны
- **Mobile**: до 1199px
  - Только центральная карточка
  - Стрелки скрыты
  - Управление свайпами

### Анимации и переходы
- Длительность анимации карточек: **0.6 секунды** (desktop), **0.4 секунды** (mobile)
- Тип анимации: `cubic-bezier(0.4, 0, 0.2, 1)`
- Автоматическая смена карточек: **5 секунд** на карточку

### Основные функции JavaScript

| Функция | Описание | Где используется |
|---------|----------|------------------|
| `initSlider()` | Создает карточки в DOM | При загрузке страницы |
| `nextCard()` | Переход на следующую карточку | Автопрокрутка, стрелка вправо |
| `prevCard()` | Переход на предыдущую карточку | Стрелка влево |
| `goToCard(index)` | Переход на конкретную карточку | Клик по прогресс-бару |
| `startAutoPlay()` | Запуск автопрокрутки | При загрузке, после перехода |
| `stopAutoPlay()` | Остановка автопрокрутки | На последней карточке |

```javascript
        console.error('Error loading cards:', error);
```
