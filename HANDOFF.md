# 📦 Передача верстки разработчикам

## Краткая инструкция

Этот документ содержит всю необходимую информацию для передачи верстки команде бэкенд-разработчиков.

## 📁 Что передается

1. **Полная верстка проекта** - все файлы в репозитории
2. **Документация по интеграции** - файл `INTEGRATION.md`
3. **Пример структуры данных** - файл `mock-api-response.json`

## 🎯 Что нужно сделать разработчикам

### Основные задачи:

1. **Реализовать API для загрузки карточек**
   - Endpoint: `GET /api/cards`
   - Формат ответа: см. `mock-api-response.json`

2. **Реализовать функционал "Поделиться"**
   - Endpoint: `POST /api/share` (опционально)
   - Или использовать Web Share API

3. **Реализовать функционал "Скачать"**
   - Endpoint: `GET /api/cards/{id}/download`
   - Или `GET /api/cards/download/all`

4. **Заинтегрировать фронтенд с API**
   - Заменить статические данные на загрузку с сервера
   - Добавить обработчики для кнопок Share/Download

### Подробная документация:

📖 **Открыть файл `INTEGRATION.md`** для детальной информации:
- Полное описание точек интеграции
- Примеры кода
- Чеклист задач
- Вопросы для обсуждения

## 🚀 Как запустить текущую версию

### Вариант 1: Простой способ
```bash
# Открыть index.html в браузере
open index.html
```

### Вариант 2: Локальный сервер
```bash
# Python 3
python3 -m http.server 3000

# Node.js
npx serve .

# Затем открыть http://localhost:3000
```
